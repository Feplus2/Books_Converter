## 前景挂账（仅落档，不动工）

- **MinerU 4.0 多格式 + 官方 API 开放 → 规则模式原生多格式输入**
  （2026-09-19 落档，FIXLOG 病例 051 挂账）：
  - 情报来源：用户转述 MinerU 官方动向——4.0 原生支持多种格式，
    官方即将开放 API 调用。
  - 机会：规则模式（stage1_mineru）输入面从 PDF 扩到电子书/图片/文档
    等更多格式——管线中后段（Stage 2/3/4）吃 markdown 契约不变，
    理论上只动 Stage 1 入口与任务参数面（GUI 文件过滤器、CLI 扩展名校验）。
  - 前置依赖：① MinerU 4.0 API 正式开放；② 官方支持格式清单确认
    （哪些格式、是否仍走同一解析端点、计费/限速口径）；③ 届时再评估
    与现有 stage1_mineru 的接法（原地扩展 vs 新适配器）。
  - 与病例 050 挂账的「VLM/LLM 直读文字层」专题的关系：**两条独立线**。
    本条目是规则模式的**输入面**（多格式进 Stage 1）；文字层专题是
    VLM 模式的**文字层捷径**（文字版 PDF 不走视觉管线）。互不阻塞，
    可分别立项。
  - 状态：仅落档。待其 API 落地、用户拍板后再立项。
